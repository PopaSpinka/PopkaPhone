# Установка с нуля

Pixel 5 (`redfin`) с открытым загрузчиком → заводской Android 13 → Ubuntu Touch 24.04 (Halium 13) → оболочка
НаомиФона. Потом, по желанию, — приставка на Raspberry Pi, окно на Mac, планшет, телевизор, Android-приложения, игры.

**До начала прочтите:**

- **Установка стирает телефон целиком.** Вернуться на Android можно (раздел «Возврат»), данные — нет.
- Это тестовый стенд, не телефон на каждый день: мобильная сеть у нас не заработала (HWTEST.md),
  ADB открыт без ключа, у пользователя `phablet` `sudo` без пароля — кто подключит кабель, получит всю систему.
- Проект закрыт и выложен как есть: что проверено и что нет — написано в каждом документе. На вопросы автор может не
  ответить.
- Команды написаны и проверены на **macOS**. Это обычные Python и sh поверх `adb`, `fastboot`, `ssh` — на Linux
  должны работать, но это не проверено; `tools/pi-card` — только macOS (`diskutil`).

## Что понадобится

- Google Pixel 5 (`redfin`), у которого загрузчик можно открыть (у версий операторов, например Verizon, — нельзя), и
  кабель USB-C.
- Компьютер: `adb` и `fastboot` (Android platform-tools; на Mac — `brew install android-platform-tools`), `python3`,
  `curl`, `unzip`, `zstd`, `ssh`. Свободного места — около 10 ГБ.
- Для рабочего стола на мониторе: Raspberry Pi 5, карта microSD, монитор с HDMI, кабель USB-C ↔ USB-A от телефона к Pi,
  сеть для Pi (кабель Ethernet), клавиатура и мышь (USB в Pi или Bluetooth).

## 1. Открыть загрузчик

Один раз, на заводском Android: «Настройки» → «О телефоне» → семь нажатий на «Номер сборки»; «Для разработчиков» →
включить «Заводская разблокировка» (OEM unlocking) и «Отладка по USB». Затем:

```sh
adb reboot bootloader
fastboot flashing unlock      # на телефоне — подтвердить кнопками громкости и питания. СТИРАЕТ ВСЁ
```

## 3. Прошивка

`tools/flash.sh` работает только с одним подключённым телефоном, только с `redfin` и только с открытым загрузчиком;
перед записью сверяет SHA-256.

```sh
tools/flash.sh bootloader     # в загрузчик (или кнопками: выключить, зажать питание + громкость вниз)
tools/flash.sh stock          # заводской Android 13 — СТИРАЕТ ВСЁ; телефон остаётся в загрузчике
tools/flash.sh ubuntu images/port-ci-16320685262/out
tools/flash.sh status         # что сейчас на телефоне
```

`stock` шьёт загрузчик и модем, только если версия другая, затем `fastboot -w --skip-reboot update`. `ubuntu` в
fastbootd удаляет логические разделы `product_a` и `system_ext_a` (иначе `ubuntu.img` не помещается в `super`), пишет
`ubuntu.img` в `system_a`, стирает `userdata`; в загрузчике пишет `boot`, `vendor_boot`, `dtbo`, слот `a`,
перезагрузка. 10 ноября 2026: `stock` — 186 с, `ubuntu` — около 2 минут.

## 4. Первый запуск Ubuntu Touch

Несколько минут. На экране мастер Ubuntu Touch: язык, **Wi-Fi** (подключите — следующим шагам нужен интернет на
телефоне), **пароль или код блокировки** (без него режим разработчика не включить). До конца мастера компьютер видит телефон только как «Google Pixel 5» (MTP), без ADB.

Потом: «Настройки системы» → «О телефоне» → «Режим разработчика» — включить. Экран при этом должен быть
разблокирован.

## 5. Доступ

```sh
tools/naomi access
adb shell -t sudo sh /tmp/naomi-dev-access.sh     # спросит пароль телефона — вводите сами
```

Первая команда создаёт для телефона свой ключ SSH (`private/ssh`, в git не идёт) и кладёт его на телефон. Вторая
(`device/dev-access.sh`) на время открывает корень на запись, даёт `phablet` `sudo` без пароля, разрешает SSH
только по ключу и только `phablet`, включает SSH. Дальше — `tools/naomi ssh`. После перепрошивки удалите старый
`private/ssh/known_hosts`.

## 6. Оболочка

```sh
tools/naomi setup
```

Сначала команда проверяет, что у телефона есть интернет (нет — скажет подключить Wi-Fi: «Настройки системы» →
Wi-Fi), и ставит его часы по компьютеру, если они ушли. Дальше по порядку (каждый шаг можно запустить и отдельно,
повторять безопасно):

| Шаг | Команда | Что делает |
|---|---|---|
| 1 | `tools/naomi usb install` | свой режим USB: ADB и сеть по кабелю всегда, вместо `usb-moded`; macOS один раз спросит, разрешить ли аксессуар ([DEVELOPMENT.md](DEVELOPMENT.md)) |
| 2 | `tools/naomi devroot` | среда сборки на телефоне: копия корня (3,3 ГБ) и пакеты сборки (≈ 175 МБ скачивания, ≈ 10 минут) |
| 3 | `tools/naomi build` | исходники `shell/` на телефон и сборка |
| 4 | `tools/naomi install` | службы: оболочка с включения, служба железа, безопасный режим, кнопка питания; главный экран по умолчанию (`device/default-project.json`: часы, заряд, «Настройки») |
| 5 | `tools/naomi fonts` | шрифты и значки интерфейса (≈ 20 МБ с GitHub) |
| 6 | `tools/naomi dict` | словари клавиатуры, русский и английский (≈ 30 МБ с GitHub) |
| 7 | `tools/naomi web-filters` | списки блокировки рекламы для браузера (≈ 5 МБ) |
| 8 | `tools/naomi lomiri off` | выключить штатную оболочку Lomiri |
| 9 | `tools/naomi run` | запустить оболочку |

На телефоне — главный экран НаомиФона: часы, «Настройки», шторка сверху. Что есть в оболочке — [SHELL.md](SHELL.md).

**Проверено 22 ноября 2026** — этими командами, из копии проекта без единого личного файла, на стёртом Pixel 5:
`flash.sh stock` — 99 с, `flash.sh ubuntu` — 59 с, `tools/naomi setup` — 13 минут (из них пакеты сборки и сборка —
около 10); после него: службы `naomi-shell`, `naomid`, `naomi-usb` работают, на телефоне главный экран с часами, стол
открывается в окне Mac и на мониторе приставки, браузер запускается.

## 7. Рабочий стол на мониторе: приставка на Raspberry Pi 5

```sh
tools/pi-card                 # какие внешние диски видит Mac
tools/pi-card diskN           # записать Raspberry Pi OS Lite на карту — СТИРАЕТ ВСЁ НА НЕЙ; спросит пароль Mac
```

Образ Raspberry Pi OS Lite 64-bit (`2026-10-06-raspios-trixie-arm64-lite.img.xz`, 550 МБ) скачайте с
`downloads.raspberrypi.com` в `downloads/raspios/` — суммы закреплены в `tools/pi-card`. На карту кладётся настройка
первого запуска: имя `naomi-pi`, пользователь `naomi`, вход только вашим ключом `private/ssh`, пароля нет.

Карту — в Pi, Pi — в сеть кабелем и в монитор, включить, подождать пару минут. Затем:

```sh
tools/pi build                # исходники на Pi и сборка приёмника naomi-dock
tools/pi install              # служба с включения Pi, интернет телефону по кабелю
tools/pi fonts                # шрифты часов заставки
tools/pi phone                # познакомить Pi с телефоном (и после каждой перепрошивки телефона)
```

`tools/pi phone` запускайте, пока телефон отвечает компьютеру (кабелем к нему или по Wi-Fi): у Pi свой ключ, которым
можно только открыть поток трансляции. Потом телефон — кабелем USB в Pi (или оставьте по Wi-Fi в той же сети). Стол включается плиткой «трансляция» в шторке телефона; клавиатура и мышь — в USB Pi или
по Bluetooth (`tools/pi pair`). 22 ноября 2026 проверено на уже записанной карте: `build`, `install`, `fonts`, `phone` из чистой копии — стол на
мониторе (телефон по Wi-Fi); запись карты `tools/pi-card` в этот проход не повторяли. Подробности, замеры и что не
проверено — [PI.md](PI.md), сам стол —
[DESKTOP.md](DESKTOP.md), несколько экранов — [SCREENS.md](SCREENS.md).

## 8. Другие экраны

- **Окно на Mac** ([STREAM.md](STREAM.md)): `cd mirror && npm install` (скачает Electron, ≈ 100 МБ), потом
  `tools/mirror` — окно сразу, или `mirror/build.sh` — приложение в «Программы». Готового приложения нет: оно
  собирается у вас, потому что помнит путь к вашей копии проекта и ключу.
- **Планшет Android** ([TABLET.md](TABLET.md)): нужны Android SDK (build-tools 35.0.0, платформа android-34) и JDK 17.
  Планшет по USB с отладкой: `tools/tablet install`, `tools/tablet pair`.
- **Телевизор Android TV** ([TV.md](TV.md)): на телевизоре включить отладку по сети; `tools/tv connect АДРЕС`,
  `tools/tv install`, `tools/tv pair`, `tools/tv access on`.

## Возврат

```sh
tools/naomi lomiri on             # вернуть штатную оболочку Ubuntu Touch
tools/naomi install uninstall     # убрать службы НаомиФона
tools/naomi usb uninstall         # вернуть usb-moded
tools/flash.sh stock              # или сразу назад на заводской Android — СТИРАЕТ ВСЁ
```

После `stock` загрузчик можно закрыть: `fastboot flashing lock` (тоже стирает).
